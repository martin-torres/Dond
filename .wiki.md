# Project Summary
**DineIn** is an advanced restaurant management platform that enhances the dining experience for customers and streamlines operations for restaurant staff. It features a customer-facing app for reservations, multilingual menus, and ordering, alongside a robust staff dashboard for kitchen, bar, and management operations. The platform supports real-time data synchronization, payment processing, and interactive floor plan management, making it a comprehensive solution for restaurant management.

# Project Module Description
- **Customer App**: Guest-facing interface for making reservations, viewing menus, and placing orders.
- **Staff Dashboard**: Dedicated views for kitchen staff, bar management, and front-of-house operations.
- **Owner/Admin Console**: Tools for restaurant management and analytics.
- **API Layer**: Manages CRUD operations for restaurants, menus, orders, and payments.
- **Interactive Floor Plan**: Allows staff to manage table assignments and layouts dynamically.
- **Real-time Updates**: Ensures that all users have access to the most current information.

# File Description Inventory
- **README.md**: Documentation for project setup and usage.
- **src/App.tsx**: Contains main application logic, including the dessert ordering flow and payment processing.
- **src/api/**: Contains API interaction files for managing restaurants, menus, orders, and payments.
- **src/components/**: Reusable UI components such as buttons, cards, modals, and new bill payment functionalities.
- **src/hooks/**: Custom hooks for managing state and handling errors.
- **src/data/**: Mock data for restaurants and menus, including updated restaurant details and premium desserts.
- **src/staff/**: Components specific to the staff dashboard for various operational views.
- **src/types/**: Type definitions for restaurant-related data structures.
- **src/lib/translations.ts**: Translation utilities for multi-language support.

# Technology Stack
- **React**: Front-end library for building user interfaces.
- **TypeScript**: For type safety and improved development experience.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Vite**: Build tool for faster development and hot module replacement.
- **React Router**: For client-side routing.
- **Supabase**: Backend as a service for database management.
- **Shadcn/UI**: Component library for UI elements.
- **Radix UI**: UI primitives for building accessible components.
