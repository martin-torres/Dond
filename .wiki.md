# Project Summary
**DineIn** is an innovative restaurant management platform designed to enhance the dining experience for customers while optimizing operational efficiency for restaurant staff. It includes a customer app for reservations, multilingual menus, and ordering, along with a comprehensive staff dashboard for kitchen, bar, and management. The platform features real-time data synchronization, payment processing (including cash options), and interactive floor plan management, delivering a complete solution for restaurant management.

# Project Module Description
- **Customer App**: User-friendly interface for reservations, menu viewing, and order placement.
- **Staff Dashboard**: Dedicated views for kitchen staff, bar management, and front-of-house operations.
- **Owner/Admin Console**: Tools for restaurant oversight and analytics.
- **API Layer**: Facilitates CRUD operations for restaurants, menus, orders, and payments.
- **Interactive Floor Plan**: Enables dynamic management of table assignments and layouts.
- **Real-time Updates**: Ensures all users have access to the latest information.

# File Description Inventory
- **README.md**: Documentation for project setup and usage.
- **src/App.tsx**: Contains main application logic, including the dessert ordering flow and payment processing.
- **src/api/**: API interaction files for managing restaurants, menus, orders, and payments.
- **src/components/**: Reusable UI components such as buttons, cards, modals, and payment functionalities.
- **src/hooks/**: Custom hooks for managing state and handling errors.
- **src/data/**: Mock data for restaurants and menus, now replaced with production data.
- **src/staff/**: Components specific to the staff dashboard for various operational views.
- **src/types/**: Type definitions for restaurant-related data structures.
- **src/lib/translations.ts**: Translation utilities for multi-language support.

# Technology Stack
- **React**: Front-end library for building user interfaces.
- **TypeScript**: For type safety and improved development experience.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Vite**: Build tool for faster development and hot module replacement.
- **React Router**: For client-side routing.
- **Supabase**: Backend as a service for database management.
- **Shadcn/UI**: Component library for UI elements.
- **Radix UI**: UI primitives for building accessible components.
