# Project Summary
**DineIn** is an advanced restaurant management platform designed to enhance the dining experience for customers and streamline operations for restaurant staff. It features a customer app for reservations, multilingual menus, and ordering, alongside a comprehensive staff dashboard for kitchen, bar, and management. The platform includes a newly integrated To-Go ordering system that allows customers to place orders without table selection, facilitating efficient takeout services. Key functionalities include real-time data synchronization, payment processing, and an interactive floor plan management system, all supported by Supabase for robust backend operations.

# Project Module Description
- **Customer App**: Interface for reservations, menu viewing, and order placement, now featuring a To-Go ordering flow.
- **Staff Dashboard**: Views for kitchen staff, bar management, and front-of-house operations.
- **Owner/Admin Console**: Tools for restaurant oversight and analytics.
- **API Layer**: Manages CRUD operations for restaurants, menus, orders, and payments.
- **Interactive Floor Plan**: Manages table assignments and layouts dynamically.
- **Real-time Updates**: Provides users with the latest information.
- **Supabase Integration**: Handles backend operations and data synchronization.

# Usage
1. **Install Dependencies**: Run the command to install all necessary packages.
2. **Build the Project**: Use the build command to create a production-ready build.
3. **Run the Application**: Start the application using the appropriate command.
4. **Connect Supabase**: Create a `.env` file with your Supabase credentials:
   ```bash
   VITE_SUPABASE_URL=your_actual_supabase_url
   VITE_SUPABASE_ANON_KEY=your_actual_anon_key
   ```
   Restart the development server after creating the `.env` file.
5. **Database Schema**: Ensure to create the necessary database schema in Supabase for the `bills` table and temporary to-go table support.
