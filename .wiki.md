# Project Summary
**DineIn** is an innovative restaurant dining application designed to enhance the dining experience by allowing users to make reservations, view multilingual menus, and place orders directly from their mobile devices. Key features include a language selector, location-based restaurant discovery, real-time wait times, sophisticated payment systems, and a dessert ordering flow that prioritizes dessert offerings, boosting sales for both diners and restaurant operators.

# Project Module Description
- **Language Selector**: Users can choose from multiple supported languages.
- **Restaurant Discovery**: Displays nearby restaurants based on user location.
- **Reservation System**: Enables real-time table reservations.
- **Bar Functionality**: Allows users to order drinks while waiting for their table.
- **Menu Ordering**: Users can browse and order from multilingual restaurant menus.
- **Payment Processing**: Facilitates bill splitting and tipping, including advanced itemized splitting.
- **Responsive Design**: Optimized layout for mobile devices.
- **Error Handling**: Features an error boundary component for graceful error management.
- **QR Code Integration**: Module for scanning QR codes for restaurant services.
- **Dessert Offer Modal**: Prompts users to order desserts before food, emphasizing limited availability.

# File Description Inventory
- **README.md**: Documentation for project setup and usage.
- **src/App.tsx**: Contains main application logic, including the dessert ordering flow and payment processing.
- **src/pages/**: Various application pages including QR scanner, restaurant info, and table selection.
- **src/components/**: Reusable UI components such as buttons, cards, modals, and new bill payment functionalities.
- **src/hooks/**: Custom hooks for managing state and handling errors.
- **src/data/mockRestaurants.ts**: Mock data for restaurants and menus, including updated restaurant details and premium desserts.
- **src/types/**: Type definitions for restaurant-related data structures.
- **src/lib/translations.ts**: Translation utilities for multi-language support.
