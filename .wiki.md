# Project Summary
**DineIn** is a cutting-edge restaurant dining application that revolutionizes the dining experience by enabling users to make reservations, explore multilingual menus, and place orders directly from their mobile devices. It features a language selector, location-based restaurant discovery, real-time wait times, and a bar tab functionality, ensuring a seamless and user-friendly interface for diners and restaurant operators alike.

# Project Module Description
- **Language Selector**: Users can choose their preferred language, now supporting 8 languages.
- **Restaurant Discovery**: Displays nearby restaurants based on user location.
- **Reservation System**: Enables table reservations with real-time availability updates.
- **Bar Functionality**: Allows users to order drinks while waiting for their table.
- **Menu Ordering**: Users can browse and order from restaurant menus in their selected language.
- **Payment Processing**: Facilitates bill splitting and tipping within the app.
- **Responsive Design**: Enhanced layout for optimal viewing on mobile devices.
- **Error Handling**: New error boundary component for graceful error management.

# File Description Inventory
- **README.md**: Documentation for project setup and usage.
- **src/App.tsx**: Main application logic with routing and error boundaries.
- **src/pages/**: Contains various pages such as Language Selector, Restaurant List, Restaurant Details, etc.
- **src/components/**: Reusable UI components like buttons, cards, and modals.
- **src/hooks/**: Custom hooks for managing state, error handling, and side effects.
- **src/data/mockData.ts**: Mock data for restaurants and menus.
- **src/lib/translations.ts**: Translation utilities for multi-language support.
